# Design Changes from Assignment 01

## 1. Web Layer — PHP → Node.js + React
**Why:** Better control over frontend for step-based task flow.
**Impact:** Same Docker architecture, better UX.

## 2. Added Two Served Sites
**Stage 2:** Forensics archive at /forensics/
**Stage 3:** Staging portal at /staging/
**Why:** More realistic scenario — separate corporate systems.

## 3. UI Improvements
**Live timer** — starts on first Challenge access, stops at 6/6.
**Hint delay** — 30 seconds after reaching a task.
**Modern scoreboard** — trophy badges + per-player timing.
**Why:** Improves player experience and reinforces time-based scoring.
